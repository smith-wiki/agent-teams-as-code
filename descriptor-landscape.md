# Existing descriptors cover different agent concerns

The candidates describe **different layers**, not interchangeable versions of one standard:

| Format | Useful declaration | Missing for this question |
|---|---|---|
| [Oracle Open Agent Specification 26.1.0](https://oracle.github.io/agent-spec/development/agentspec/language_spec_26_1_0.html) | Serializable agents, prompts, tools and flows with nodes/edges; [runtime adapters](https://github.com/oracle/agent-spec#executing-agent-spec-configurations) can execute supported subsets. | No general account provisioning, enforced host ACL or sleep lifecycle. Tool confirmation is not an ACL. |
| [AGNTCY OASF Agent Record](https://docs.agntcy.org/oasf/agent-record-guide/) | Catalog record with name, version, classified skills, domains, locators and optional modules. | Discovery metadata is neither a runnable team nor access control; validation checks shape, not the truth of claims. Its [Agent Spec module](https://github.com/agntcy/oasf/blob/main/schema/modules/integration/agentspec.json) embeds another format rather than supplying execution semantics. |
| [A2A Agent Card 1.0](https://a2a-protocol.org/v1.0.0/specification/#44-agent-discovery-objects) | Public discovery of remote agent skills, endpoint and [authentication requirements](https://a2a-protocol.org/v1.0.0/specification/#45-security-objects); protocol covers remote async tasks. | Internal tools, team topology, local permissions and process suspension are outside its scope ([principles](https://a2a-protocol.org/v1.0.0/specification/#12-guiding-principles)). |
| [CrewAI configuration](https://docs.crewai.com/v1.15.22/en/concepts/agents#creating-agents) | Runnable framework-specific roles, goals, tools and [crew tasks/process](https://docs.crewai.com/v1.15.22/en/concepts/crews). New crews favor JSONC; classic YAML remains supported. | No provider account reconciliation or general host permission policy; checkpointing is not automatic idle sleep. |
| [Microsoft APM](https://microsoft.github.io/apm/reference/manifest-schema/) | `apm.yml` declares versioned agent primitives and MCP dependencies; [package layouts](https://microsoft.github.io/apm/reference/package-types/) can ship `.apm/agents/*.agent.md`; `apm install` routes them to supported harnesses. [`apm-policy.yml`](https://microsoft.github.io/apm/enterprise/policy-reference/) governs installation; [`apm run`](https://microsoft.github.io/apm/reference/cli/run/) can invoke a shell script. | Installation policy is not runtime access control; it does not create Zulip/mail accounts, model a team's live sessions, or suspend agents. [Target support varies](https://microsoft.github.io/apm/reference/targets-matrix/). See [APM's precise fit](microsoft-apm.md). |
| [Google AX](https://github.com/google/ax/blob/e09ed1bc5463ad4b5ca88f755a6e1e2005b3c7b7/pkg/apis/v1alpha1/ax.proto) | Declarative `Task`, `Workspace`, `Model`, explicit suspend/resume for an execution sandbox. | No team/role/account/session resource. Automatic idle suspension and tighter sandbox policies are [roadmap work](https://github.com/google/ax/blob/e09ed1bc5463ad4b5ca88f755a6e1e2005b3c7b7/docs/roadmap.md). |

**Updated decision:** the [repository's agent definitions](agent-manifest.md), not an APM-specific team object, define membership. [APM](microsoft-apm.md) remains an optional way to distribute profiles to several harnesses; for one chosen harness, [Nix can build an OCI container image](https://nixos.org/manual/nixpkgs/stable/#ex-ociTools-buildContainer-bash) containing its native configuration without APM. Neither build path provisions provider accounts, enforces external grants or coordinates event-driven sessions: these are separate **per-agent** controller concerns ([language comparison](agent-language-options.md), [control plane](agent-control-plane-options.md)). An adapter must **actually enforce** grants; writing `read-only` in a prompt is not a credential policy. Emit A2A cards only for exposed agents, translate to Agent Spec/CrewAI only when a chosen runtime requires it, and send execution settings to AX only when using AX; do not claim lossless cross-format conversion. Compare [Microsoft's other declarative agents](microsoft-declarative-agents.md).
